Тесты для приложения BooksCollector
test_add_new_book_add_two_books — добавляет новую книгу в словарь без указания жанра.
test_add_new_book_with_invalid_lenght - не добавляет книгу, если символов 0 или больше 40.
test_set_book_genre_if_book_in_books_genre_and_genre — устанавливает жанр книги, если книга есть в books_genre и её жанр входит в список genre.
test_get_book_genre_for_name — выводит жанр книги по её имени.
test_get_books_with_specific_genre — выводит список книг с определённым жанром.
test_get_books_genre — выводит текущий словарь books_genre.
test_get_books_for_children — возвращает книги, которые подходят детям. У жанра книги не должно быть возрастного рейтинга.
test_add_book_in_favorites — добавляет книгу в избранное. 
test_delete_book_from_favorites — удаляет книгу из избранного
test_get_list_of_favorites_books - выводит список, который содержит избранные книги.
